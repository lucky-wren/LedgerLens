# 账镜 LedgerLens · 云端部署包使用说明

> 版本 **1.2.1**　·　构建时间 2026/11/9 22:20:28（北京时间）
>
> 这份文件**只是说明**，网站运行不需要它。不想让它在站点上被访问到，删掉即可；`CHANGELOG.md` 同理。

---

## 一、先说清楚这是什么

一个**纯静态网站**：没有服务端、没有数据库、不需要 Node 在服务器上跑。

把收银系统导出的 Excel / CSV / JSON 放进去，它会在浏览器里把账目算清楚、画成 8 张图、用大白话给出「接下来该做点什么」。**账目一次都不会上传**，全部存在使用者自己电脑的浏览器里。

- 是：一台电脑、一两个人、每周导一次表就能用的账目分析工具
- 不是：带账号 / 权限 / 审计 / 自动定时拉取的公司系统
- 不连：思迅、客如云、医保、PMS 等收银系统内部，只吃它们**导出来的文件**

## 二、最快上线：三步

1. **解压**这个压缩包，得到一个文件夹（里面就是第四节列的那几样东西）
2. 把**整个文件夹原样上传**到任意静态托管（别只传 `index.html`，会缺样式和脚本）
3. 浏览器打开托管给你的地址，看到蓝色的一句话结论横幅，就成了

不需要：`npm install`、Node、数据库、容器、构建命令、环境变量。

## 三、三种部署方式

### A · 任意静态托管（最常用）

把解压后的目录整个上传，入口是 `index.html`。适用于：

- 腾讯云 CloudBase 静态网站托管 / COS 静态网站、阿里云 OSS、又拍云
- Netlify / Vercel：选「静态站点，无构建命令」，发布目录指向这个文件夹
- 自己的 Nginx：

```nginx
server {
  listen 443 ssl;
  server_name ledger.example.com;
  root /var/www/ledgerlens;   # 指向解压后的目录
  index index.html;
  location / { try_files $uri $uri/ /index.html; }
  location ~* \.(js|css|png|svg|webmanifest)$ { add_header Cache-Control "public, max-age=3600"; }
}
```

### B · GitHub Pages（源码包里已配好工作流）

部署包里只有网站文件；**完整源码包**里的 `.github/workflows/deploy.yml` 会在 push 到 `main` 时自动：构建 → 跑单测 → 上传 `dist/` → 发布。

仓库 **Settings → Pages → Source** 选 **GitHub Actions** 即可。放在 `https://<用户名>.github.io/<仓库名>/` 这种子路径下也没问题：所有资源引用都是相对路径（`./assets/...`、`./manifest.webmanifest`、`./sw.js`），PWA 的 `start_url` 与 `scope` 也都是 `./`。

### C · 只是在自己电脑上看一眼

- **想离线、不想起服务器**：直接双击 `账镜-单文件版.html`，U 盘 / 邮件附件 / 断网都能用，功能和网站一致。
- **想按网站的方式预览**：用完整源码包，需要 Node ≥ 18，执行 `node build.mjs && node serve.mjs`，然后打开 `http://127.0.0.1:8080/`。

## 四、这个包里都有什么

| 文件 | 干什么 | 能不能删 |
|---|---|---|
| `index.html` | 网站入口，**必需** | ❌ |
| `assets/app.js` / `assets/app.css` | 全部逻辑与样式，**必需** | ❌ |
| `assets/favicon.svg` / `favicon.svg` | 浏览器标签上的小图标 | 可删，只是不好看 |
| `manifest.webmanifest`、`icon-192.png`、`icon-512.png` | 「安装到桌面」用的 PWA 配置与图标 | 可删，删了就不能安装 |
| `sw.js` | 断网时还能打开页面的离线缓存 | 可删，删了断网打不开 |
| `robots.txt` | 告诉搜索引擎可以收录 | 可删 |
| `VERSION.json` | 版本、构建时间、入口文件名，用来核对发的是不是新版 | 可删 |
| `账镜-单文件版.html` | 全部内联的离线版，可单独发给别人 | 可删，网站运行不需要 |
| `README.md` / `CHANGELOG.md` | 你正在看的说明与版本记录 | 可删 |

**文件总数不多，整包约几百 KB，上传很快。**

## 五、发新版怎么更

版本号写在资源 URL（`app.js?v=1.2.1`）、`sw.js` 的缓存名和 `VERSION.json` 里，**重新上传整个目录，旧缓存会自动失效**，用户不会卡在旧页面。

要自己出新版，用完整源码包：改 `site.config.json` 的 `version`（或 `node build.mjs --version 1.2.2`），执行 `node build.mjs`，再把新的 `dist/` 整个传上去。`npm run pack` 会重新生成这两个压缩包并自动检查清单。

## 六、常见问题

| 现象 | 怎么办 |
|---|---|
| **双击 `index.html` 打开是空白 / 报错** | 网站版必须通过 `http://` 或 `https://` 访问，`file://` 下 Service Worker 和 manifest 不工作。要么上传到静态托管，要么用源码包的 `node serve.mjs`，要么直接双击 `账镜-单文件版.html`。 |
| **上传了，页面还是旧样子** | 强刷一次（Ctrl+F5）。版本号已写进资源 URL 和缓存名，正常情况下重新上传整个目录就会自动更新。 |
| **「安装到桌面」按钮没有 / 装不上** | PWA 需要 `https://` 或 `localhost`；用 HTTP 内网访问时其它功能都正常，只是不能安装。 |
| **放在子目录（如 `/ledger/`）能用吗** | 能，资源全是相对路径。 |
| **换台电脑，之前导入的账没了** | 数据存在浏览器本机（`localStorage`），不跨设备。请用「导出表格」留底，或在新电脑上重新导入一次。 |
| **能不能几个人一起用、每天自动更新** | 不能。这需要账号、服务端和数据库，是另一个项目，不是改几行配置能解决的。 |

## 八、边界，再说一次

- 静态站点 = **没有服务端**，账目一次都不会上传；所有计算都在浏览器里完成。
- 数据存在使用者本机浏览器里，换电脑不跟着走，请导出表格留底。
- 厂商接口直连、多人账号、操作审计、定时拉取、经营净利（房租人工水电）**都不做**。
- 需要多人协作、每天自动更新、留操作记录时，应该另起一套带服务端的项目，而不是往这个静态站点里塞后端。
