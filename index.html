这些词到底啥意思

全是大白话，看完再回去看数字就不懵了

一句话记住：「收了多少钱」不等于「赚了多少钱」。收的钱里要扣掉退款，再扣掉进货成本，剩下的才叫赚的差价；房租、人工、水电还要再扣，那部分本工具暂时算不了。
词大白话解释
净营收 / 进账客人实际付进来的钱，扣掉退回去的钱和支出之后，真正留下的那部分。
毛利额 / 赚的差价卖价减去进货价，剩下的钱。还没扣房租、人工、水电，所以不等于最后落到口袋的利润。
毛利率 / 差价占比每收进来 100 元，里面大概有几元是差价。比如 30% 就是 100 元里有 30 元差价。
成本 / 进价你进货花掉的钱。表里没有这一列时，毛利就算不出来，会显示「—」而不是瞎猜一个 0。
客单价平均一位客人一次花了多少钱。总进账 ÷ 单数。
有效订单数 / 单数这段时间一共做了多少笔生意，同一个单号只算一次。
退款率收进来的钱里，有多少又退回给客人了。太高就要查是不是录错单或者商品有问题。
日均平均每天进账多少，把没开门的日子也算进去。
环比 / 跟上期比拿最近一段时间，跟前面同样长的一段时间比。为了公平，两边都按整周算，星期构成一样。
成本覆盖率有多少笔账是带进价的。比如 80%，就说明还有两成没记进价，算毛利时先把它们放在一边，不硬算。
业态 / 生意类型你做的是超市、药店还是酒店。不同生意的正常退款率、正常差价比例不一样，所以标准也不同。
品类东西的分类，比如「生鲜」「房费」「感冒药」。也用来分酒店里的房费、餐饮、会议等收入项。
倒挂 / 卖一件亏一件卖价还没进价高，这类东西卖得越多亏得越多，图上用红色标出来。
引流品本身不怎么赚钱、但能把客人引进来的东西（比如便宜的生鲜）。别只看它赚多少，要看它有没有带动别的商品。
还有个容易弄错的地方：金额符号（¥ / £ / €）只是改个显示，不会帮你换算汇率。如果一份表里混了几种钱，要先自己折成同一种再放进来。

哪些事它还做不了

先说清楚边界，免得你白等

一句话说清它是干什么的：不进你的收银系统，只「吃它导出来的表」。把超市、药店、酒店后台导出的日结流水或对账单放进来，它帮你算清楚收了多少、赚了多少、哪里要留意、下一步做啥。不需要厂商配合，也不需要网络。

它算的是「赚的差价」，不是最后落到口袋的钱。卖价减进价就是差价，房租、人工、水电、平台抽成、税这些还没扣。要看净利，得另外有这些费用数据。
  • 现在能做：读 Excel（.xlsx）、CSV、TXT、JSON 和从 Excel 粘贴；栏目名不一样也能认；重复导入自动跳过；可选金额符号；算营收、退款、差价、客人平均消费；画 8 张图（点柱子能只看一项）；逐笔搜单号；给大白话建议（能标记已处理并回看数字）；自己调判定标准；导出带封面的报告（网页 / Word / Markdown / PDF）和好看的 Excel 明细表。
  • 现在做不了：老版 .xls、加了密码的 Excel、小票拍照识别、直接连数据库、厂商接口对接、实时到账、多人账号与权限、自动定时拉取、把建议派给某个人的任务系统。这些都是以后才考虑的事，不影响现在算账。判定标准只存在这台电脑，换一台要重新设。
  • 几个容易弄错的地方：表里没写进价就算不出赚的差价（会显示「—」，不会瞎填 0）；金额符号只是改显示，不会帮你换汇率；一份表里混了几种货币，要先自己折成同一种；每品类各占一列的「宽表」要先整理成一行一笔才能放进来。
  • 数据在哪：全部在你这台电脑的浏览器里算，不会上传。导入的账目和栏目对照记在本机，刷新还在，点左栏「清空我的账目」即可清掉。
想给多人用、每天自动更新、或者要留操作记录？那就不是改几句话的事了，得另做一套带账号和服务端的版本。现在这个是「一台电脑、一两个人、每周导一次表」用的，别拿它当全公司的系统。
